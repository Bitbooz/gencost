Korzystaj z GenCost w Claude, ChatGPT i Cursor

GenCost ma darmowy serwer MCP. Podłącz go do swojego asystenta AI, a gdy zapytasz „Ile kosztuje Runway?” albo „Które narzędzie AI do wideo jest najtańsze za klip?”, odpowiedź będzie pochodziła z dzisiejszych zweryfikowanych cen, a nie z pamięci modelu.

Adres serwera
https://getgencost.com/mcp
Darmowy, tylko do odczytu, bez logowania. Ceny są pobierane codziennie rano z oficjalnych stron cenowych każdego narzędzia.

O co możesz pytać

  • „Ile kosztuje ElevenLabs miesięcznie i na co uważać?”
  • „Porównaj Midjourney, Ideogram i Recraft.”
  • „Które narzędzie AI do wideo jest najtańsze za klip 5-sekundowy?”
  • „Wymień narzędzia AI do muzyki z darmowym planem.”

Claude

W Claude otwórz Ustawienia → Łączniki, wybierz Dodaj łącznik niestandardowy, nazwij go GenCost i wklej powyższy adres serwera. Potem włącz go w czacie z menu narzędzi.

W Claude Code wpisz:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

Tam, gdzie Twój plan ChatGPT obsługuje łączniki niestandardowe (tryb deweloperski), dodaj nowy łącznik i wklej adres serwera. Nie wymaga uwierzytelniania.

Cursor, VS Code i inne klienty MCP

Dodaj to do swojej konfiguracji MCP (dla Cursor, ~/.cursor/mcp.json):

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

Narzędzia

NarzędzieCo robi
list_toolsKażde narzędzie śledzone przez GenCost, według kategorii, z najtańszym płatnym planem i informacją, czy ma plan darmowy
get_pricesPlany jednego narzędzia: ceny miesięczne i roczne, kredyty, koszt za klip wideo, ukryte koszty i data weryfikacji cen
compare_tools2 do 6 narzędzi obok siebie
find_cheapestNajtańsze narzędzia w kategorii, według ceny planu lub (dla wideo) kosztu za klip

Jak działają dane

Wszystkie ceny są w dolarach amerykańskich przed podatkiem. Zwracane są tylko potwierdzone ceny: nowa cena musi być odczytana w dwa różne dni, zanim zastąpi starą, a zmiany czekające na potwierdzenie są oznaczone. Każda odpowiedź zawiera oficjalną stronę cennika i datę weryfikacji. Te same dane są dostępne jako JSON: wideo, obraz, głos i muzyka.

Jeśli używasz danych GenCost w odpowiedzi, artykule lub produkcie, podaj źródło GenCost i link do strony narzędzia na getgencost.com.
