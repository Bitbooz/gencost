Claude, ChatGPT ও Cursor-এ GenCost ব্যবহার করুন

GenCost-এর একটি ফ্রি MCP সার্ভার আছে। এটি আপনার AI অ্যাসিস্ট্যান্টের সাথে কানেক্ট করুন, এবং যখন আপনি জিজ্ঞাসা করবেন "Runway-এর খরচ কত?" বা "কোন AI ভিডিও টুল প্রতি ক্লিপে সবচেয়ে সস্তা?", উত্তর আসবে আজকের যাচাইকৃত দাম থেকে, মডেলের মেমরি থেকে নয়।

সার্ভার অ্যাড্রেস
https://getgencost.com/mcp
ফ্রি, রিড-অনলি, কোনো সাইন-ইন লাগে না। দাম প্রতিদিন সকালে প্রত্যেক টুলের অফিসিয়াল প্রাইসিং পেজ থেকে পড়া হয়।

আপনি কী জিজ্ঞাসা করতে পারেন

  • "ElevenLabs-এর মাসিক খরচ কত, এবং কোনো সমস্যা আছে কি?"
  • "Midjourney, Ideogram ও Recraft-এর তুলনা করে দিন।"
  • "5-সেকেন্ড ক্লিপের জন্য কোন AI ভিডিও টুল সবচেয়ে সস্তা?"
  • "ফ্রি প্ল্যান আছে এমন AI মিউজিক টুলের লিস্ট দিন।"

Claude

Claude-এ Settings → Connectors খুলুন, Add custom connector বেছে নিন, নাম দিন GenCost এবং উপরের সার্ভার অ্যাড্রেস পেস্ট করুন। তারপর টুলস মেনু থেকে চ্যাটে চালু করুন।

Claude Code-এ চালান:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

যেখানে আপনার ChatGPT প্ল্যান কাস্টম কানেক্টর সাপোর্ট করে (ডেভেলপার মোড), নতুন কানেক্টর যোগ করুন এবং সার্ভার অ্যাড্রেস পেস্ট করুন। কোনো অথেনটিকেশন লাগে না।

Cursor

এটি যোগ করুন ~/.cursor/mcp.json:

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

VS Code (GitHub Copilot)

এটি যোগ করুন .vscode/mcp.json আপনার প্রজেক্টে, অথবা ইউজার কনফিগারেশনে (কমান্ড প্যালেট: MCP: Open User Configuration). VS Code ব্যবহার করে servers, না যে mcpServers:

{ "servers": { "gencost": { "type": "http", "url": "https://getgencost.com/mcp" } } }

Codex (CLI, IDE এক্সটেনশন এবং ChatGPT ডেস্কটপ)

চালান:

codex mcp add gencost --url https://getgencost.com/mcp

অথবা এটি যোগ করুন ~/.codex/config.toml:

[mcp_servers.gencost]
url = "https://getgencost.com/mcp"

Windsurf

Cascade প্যানেলে, খুলুন MCPs এবং নির্বাচন করুন View raw config খুলতে mcp_config.json, এটি যোগ করুন, তারপর রিফ্রেশ চাপুন:

{ "mcpServers": { "gencost": { "serverUrl": "https://getgencost.com/mcp" } } }

Gemini CLI

এটি যোগ করুন ~/.gemini/settings.json. ব্যবহার করুন httpUrl (না যে url, যেটি পুরোনো SSE সার্ভারের জন্য):

{ "mcpServers": { "gencost": { "httpUrl": "https://getgencost.com/mcp" } } }

অন্যান্য MCP ক্লায়েন্ট

যেকোনো ক্লায়েন্ট যা Streamable HTTP এর মাধ্যমে রিমোট MCP সার্ভার সাপোর্ট করে কাজ করবে: ঠিকানা ব্যবহার করুন https://getgencost.com/mcp. কোনো API কী বা সাইন-ইন প্রয়োজন নেই।

টুলগুলো

টুলএটি কী করে
list_toolsGenCost যে সব টুল ট্র্যাক করে, ক্যাটাগরি অনুসারে, সবচেয়ে সস্তা পেইড প্ল্যান এবং ফ্রি প্ল্যান আছে কি না
get_pricesএকটি টুলের প্ল্যান: মাসিক এবং বার্ষিক দাম, ক্রেডিট, প্রতি ভিডিও ক্লিপের খরচ, লুকানো খরচ এবং দাম যাচাইয়ের তারিখ
compare_tools2 থেকে 6 টুল পাশাপাশি
find_cheapestএকটি ক্যাটাগরিতে সবচেয়ে সস্তা টুল, প্ল্যানের দাম অনুসারে অথবা (ভিডিওর জন্য) প্রতি ক্লিপের খরচ অনুসারে

ডেটা কীভাবে কাজ করে

সব দাম ট্যাক্সের আগে US ডলারে। শুধু নিশ্চিত দাম ফেরত দেওয়া হয়: একটি নতুন দাম দুই আলাদা দিনে পড়তে হবে পুরোনোটি প্রতিস্থাপনের আগে, এবং নিশ্চিতকরণের অপেক্ষায় থাকা পরিবর্তনগুলো চিহ্নিত করা হয়। প্রতিটি উত্তরে অফিসিয়াল প্রাইসিং পেজ এবং যাচাইয়ের তারিখ থাকে। একই ডেটা JSON হিসেবে পাওয়া যায়: ভিডিও, ইমেজ, ভয়েস এবং মিউজিক।

যদি আপনি GenCost ডেটা কোনো উত্তর, আর্টিকেল বা প্রোডাক্টে ব্যবহার করেন, তাহলে GenCost ক্রেডিট করুন এবং getgencost.com এ টুলের পেজে লিংক দিন।
