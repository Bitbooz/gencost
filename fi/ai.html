Käytä GenCostia Claudessa, ChatGPT:ssä ja Cursorissa

GenCostissa on ilmainen MCP-palvelin. Yhdistä se tekoälyassistenttiisi, niin kun kysyt "Mitä Runway maksaa?" tai "Mikä tekoälyvideotyökalu on halvinta per leike?", vastaus tulee tämän päivän varmistetuista hinnoista mallin muistin sijaan.

Palvelimen osoite
https://getgencost.com/mcp
Ilmainen, vain luku, ei sisäänkirjautumista. Hinnat luetaan jokaisen työkalun viralliselta hinnoittelusivulta joka aamu.

Mitä voit kysyä

  • "Mitä ElevenLabs maksaa kuukaudessa, ja mikä on juju?"
  • "Vertaa Midjourneyä, Ideogramia ja Recraftia minulle."
  • "Mikä tekoälyvideotyökalu on halvinta per 5-sekunnin leikkeelle?"
  • "Listaa tekoälymusiikkityökalut joissa on ilmainen suunnitelma."

Claude

Claudessa avaa Asetukset → Liittimet, valitse Lisää mukautettu liitin, nimeä se GenCost ja liitä yllä oleva palvelimen osoite. Kytke se sitten päälle chatissa työkaluvalikosta.

Claude Codessa suorita:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

Jos ChatGPT-suunnitelmasi tukee mukautettuja liittimiä (kehittäjätila), lisää uusi liitin ja liitä palvelimen osoite. Todennusta ei tarvita.

Cursor

Lisää tämä tiedostoon ~/.cursor/mcp.json:

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

VS Code (GitHub Copilot)

Lisää tämä tiedostoon .vscode/mcp.json projektissasi tai käyttäjäasetuksiin (komentopaletti: MCP: Avaa käyttäjäasetukset). VS Code käyttää servers, ei mcpServers:

{ "servers": { "gencost": { "type": "http", "url": "https://getgencost.com/mcp" } } }

Codex (CLI, IDE-laajennus ja ChatGPT-työpöytä)

Suorita:

codex mcp add gencost --url https://getgencost.com/mcp

tai lisää tämä ~/.codex/config.toml:

[mcp_servers.gencost]
url = "https://getgencost.com/mcp"

Windsurf

Cascade-paneelissa, avaa MCP:t ja valitse Näytä raaka konfiguraatio avataaksesi mcp_config.json, lisää tämä, sitten paina päivitä:

{ "mcpServers": { "gencost": { "serverUrl": "https://getgencost.com/mcp" } } }

Gemini CLI

Lisää tämä tiedostoon ~/.gemini/settings.json. Käytä httpUrl (ei url, joka on vanhemmille SSE-palvelimille):

{ "mcpServers": { "gencost": { "httpUrl": "https://getgencost.com/mcp" } } }

Muut MCP-asiakkaat

Mikä tahansa asiakas, joka tukee etä-MCP-palvelimia Streamable HTTP:n kautta: käytä osoitetta https://getgencost.com/mcp. API-avainta tai sisäänkirjautumista ei tarvita.

Miten data toimii

Kaikki hinnat ovat Yhdysvaltain dollareita ennen veroja. Vain vahvistetut hinnat palautetaan: uuden hinnan on oltava luettu kahtena erillisenä päivänä ennen kuin se korvaa vanhan, ja odottavat muutokset merkitään. Jokainen vastaus sisältää virallisen hinnoittelusivun ja varmennuspäivämäärän. Sama data on saatavilla JSONina: video, image, voice ja music.

Jos käytät GenCost-dataa vastauksessa, artikkelissa tai tuotteessa, mainitse GenCost ja linkitä työkalun sivulle osoitteessa getgencost.com.
