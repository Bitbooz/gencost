الرئيسية/الاستخدام في مساعدات الذكاء الاصطناعي

استخدم GenCost في Claude وChatGPT وCursor

يوفر GenCost خادم MCP مجاني. اربطه بمساعدك الذكي، وعندما تسأل «كم تكلفة Runway؟» أو «ما أرخص أداة فيديو بالذكاء الاصطناعي لكل مقطع؟»، تأتي الإجابة من الأسعار المُتحققة اليوم بدلاً من ذاكرة النموذج.

عنوان الخادم
https://getgencost.com/mcp
مجاني، للقراءة فقط، بدون تسجيل دخول. تُقرأ الأسعار من صفحة التسعير الرسمية لكل أداة كل صباح.

ما يمكنك سؤاله

  • «كم تكلفة ElevenLabs شهرياً، وما العيوب؟»
  • «قارن لي بين Midjourney وIdeogram وRecraft.»
  • «ما أرخص أداة فيديو بالذكاء الاصطناعي لمقطع مدته 5 ثانية؟»
  • «اعرض أدوات الموسيقى بالذكاء الاصطناعي التي لها خطة مجانية.»

Claude

في Claude، افتح الإعدادات ← الموصلات، اختر إضافة موصل مخصص، سمِّه GenCost والصق عنوان الخادم أعلاه. ثم فعِّله في دردشة من قائمة الأدوات.

في Claude Code، نفّذ:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

حيث يدعم خطة ChatGPT الموصلات المخصصة (وضع المطور)، أضف موصلاً جديداً والصق عنوان الخادم. لا يلزم أي مصادقة.

Cursor وVS Code وعملاء MCP الآخرون

أضف هذا إلى إعدادات MCP الخاصة بك (لـ Cursor, ~/.cursor/mcp.json):

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

list_toolsكل أداة يتتبعها GenCost، حسب الفئة، مع أرخص خطة مدفوعة لها وما إذا كانت لديها خطة مجانية

كيفية عمل البيانات

جميع الأسعار بالدولار الأمريكي قبل الضريبة. تُرجع الأسعار المؤكدة فقط: يجب قراءة السعر الجديد في يومين منفصلين قبل أن يحل محل القديم، وتُعلَّم التغييرات المنتظرة التأكيد. يتضمن كل رد صفحة التسعير الرسمية وتاريخ التحقق. البيانات نفسها متاحة بصيغة JSON: video وimage وvoice وmusic.

إذا استخدمت بيانات GenCost في رد أو مقالة أو منتج، يُرجى ذكر GenCost وربط صفحة الأداة على getgencost.com.
