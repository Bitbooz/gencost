Gamitin ang GenCost sa Claude, ChatGPT at Cursor

May free MCP server ang GenCost. Ikonekta ito sa AI assistant mo, at kapag tinanong mo "Magkano ang Runway?" o "Aling AI video tool ang pinakamura kada clip?", ang sagot ay mula sa verified prices ngayon, hindi sa memory ng model.

Server address
https://getgencost.com/mcp
Libre, read-only, walang sign-in. Binabasa ang presyo mula sa official pricing page ng bawat tool tuwing umaga.

Ano ang pwede mong itanong

  • "Magkano ang ElevenLabs kada buwan, at ano ang catch?"
  • "I-compare mo ang Midjourney, Ideogram at Recraft para sa akin."
  • "Aling AI video tool ang pinakamura kada 5-second clip?"
  • "Ilista ang AI music tools na may free plan."

Claude

Sa Claude, buksan ang Settings → Connectors, piliin ang Add custom connector, pangalanan itong GenCost at i-paste ang server address sa itaas. Pagkatapos ay i-on ito sa chat mula sa tools menu.

Sa Claude Code, patakbuhin:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

Kung sinusuportahan ng ChatGPT plan mo ang custom connectors (developer mode), magdagdag ng bagong connector at i-paste ang server address. Walang authentication na kailangan.

Cursor

Idagdag ito sa ~/.cursor/mcp.json:

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

VS Code (GitHub Copilot)

Idagdag ito sa .vscode/mcp.json sa project mo, o sa user configuration mo (command palette: MCP: Open User Configuration). VS Code gumagamit servers, hindi mcpServers:

{ "servers": { "gencost": { "type": "http", "url": "https://getgencost.com/mcp" } } }

Codex (CLI, IDE extension at ChatGPT desktop)

Patakbuhin:

codex mcp add gencost --url https://getgencost.com/mcp

o idagdag ito sa ~/.codex/config.toml:

[mcp_servers.gencost]
url = "https://getgencost.com/mcp"

Windsurf

Sa Cascade panel, buksan MCPs at piliin View raw config para buksan mcp_config.json, idagdag ito, pagkatapos pindutin ang refresh:

{ "mcpServers": { "gencost": { "serverUrl": "https://getgencost.com/mcp" } } }

Gemini CLI

Idagdag ito sa ~/.gemini/settings.json. Gamitin httpUrl (hindi url, na para sa mas lumang SSE servers):

{ "mcpServers": { "gencost": { "httpUrl": "https://getgencost.com/mcp" } } }

Iba pang MCP clients

Kahit aling client na sumusuporta sa remote MCP servers gamit ang Streamable HTTP ay gumagana: gamitin ang address https://getgencost.com/mcp. Walang kailangang API key o sign-in.

Ang mga tools

ToolAno ang ginagawa nito
list_toolsBawat tool na tinatrack ng GenCost, ayon sa category, kasama ang pinakamurang paid plan nito at kung may free plan ito
get_pricesMga plan ng isang tool: buwanang at taunang presyo, credits, cost per video clip, hidden costs at ang petsa kung kailan na-verify ang presyo
compare_tools2 hanggang 6 tools side by side
find_cheapestAng pinakamurang tools sa isang category, ayon sa plan price o (para sa video) sa cost per clip

Paano gumagana ang data

Ang lahat ng presyo ay nasa US dollars bago ang tax. Tanging confirmed prices lang ang ibinabalik: kailangang basahin ang bagong presyo sa dalawang magkaibang araw bago nito palitan ang luma, at ang mga changes na naghihintay ng confirmation ay minamarkahan. Bawat sagot ay kasama ang official pricing page at ang verification date. Ang parehong data ay available bilang JSON: video, image, voice at music.

Kung gagamitin mo ang GenCost data sa isang sagot, artikulo o product, pakilagyan ng credit ang GenCost at i-link sa tool's page sa getgencost.com.
