ใช้ GenCost ใน Claude, ChatGPT และ Cursor

GenCost มี MCP server ฟรี เชื่อมต่อกับ AI ผู้ช่วยของคุณ เมื่อคุณถาม "Runway ราคาเท่าไหร่?" หรือ "เครื่องมือ AI วิดีโอตัวไหนถูกที่สุดต่อคลิป?" คำตอบจะมาจากราคาที่ตรวจสอบแล้วในวันนี้ ไม่ใช่ความจำของโมเดล

ที่อยู่เซิร์ฟเวอร์
https://getgencost.com/mcp
ฟรี อ่านอย่างเดียว ไม่ต้องลงชื่อเข้าใช้ ราคาอ่านจากหน้าราคาอย่างเป็นทางการของแต่ละเครื่องมือทุกเช้า

สิ่งที่คุณสามารถถามได้

  • "ElevenLabs ราคาต่อเดือนเท่าไหร่ และมีข้อควรระวังอะไรบ้าง?"
  • "ช่วยเปรียบเทียบ Midjourney, Ideogram และ Recraft ให้หน่อย"
  • "เครื่องมือ AI วิดีโอตัวไหนถูกที่สุดต่อคลิป 5 วินาที?"
  • "รายชื่อเครื่องมือ AI เพลงที่มีแผนฟรี"

Claude

ใน Claude เปิด Settings → Connectors เลือก Add custom connector ตั้งชื่อ GenCost แล้ววางที่อยู่เซิร์ฟเวอร์ด้านบน จากนั้นเปิดใช้งานในแชทจากเมนูเครื่องมือ

ใน Claude Code ให้รัน:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

หากแผน ChatGPT ของคุณรองรับ custom connectors (โหมดนักพัฒนา) ให้เพิ่มคอนเนกเตอร์ใหม่และวางที่อยู่เซิร์ฟเวอร์ ไม่ต้องยืนยันตัวตน

Cursor

เพิ่มสิ่งนี้ไปที่ ~/.cursor/mcp.json:

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

VS Code (GitHub Copilot)

เพิ่มสิ่งนี้ไปที่ .vscode/mcp.json ในโปรเจกต์ของคุณ หรือไปที่การตั้งค่าผู้ใช้ (command palette: MCP: Open User Configuration). VS Code ใช้ servers, ไม่ใช่ mcpServers:

{ "servers": { "gencost": { "type": "http", "url": "https://getgencost.com/mcp" } } }

Codex (CLI, ส่วนขยาย IDE และ ChatGPT desktop)

รัน:

codex mcp add gencost --url https://getgencost.com/mcp

หรือเพิ่มสิ่งนี้ไปที่ ~/.codex/config.toml:

[mcp_servers.gencost]
url = "https://getgencost.com/mcp"

Windsurf

ในแผง Cascade เปิด MCPs และเลือก View raw config เพื่อเปิด mcp_config.json, เพิ่มสิ่งนี้ แล้วกดรีเฟรช:

{ "mcpServers": { "gencost": { "serverUrl": "https://getgencost.com/mcp" } } }

Gemini CLI

เพิ่มสิ่งนี้ไปที่ ~/.gemini/settings.json. ใช้ httpUrl (ไม่ใช่ url, ซึ่งสำหรับเซิร์ฟเวอร์ SSE รุ่นเก่า):

{ "mcpServers": { "gencost": { "httpUrl": "https://getgencost.com/mcp" } } }

ไคลเอนต์ MCP อื่นๆ

ไคลเอนต์ใดๆ ที่รองรับเซิร์ฟเวอร์ MCP ระยะไกลผ่าน Streamable HTTP ทำงานได้: ใช้ที่อยู่ https://getgencost.com/mcp. ไม่ต้องใช้ API key หรือลงชื่อเข้าใช้

เครื่องมือ

เครื่องมือมันทำอะไร
list_toolsทุกเครื่องมือที่ GenCost ติดตาม แยกตามหมวดหมู่ พร้อมแผนที่ถูกที่สุดและมีแผนฟรีหรือไม่
get_pricesแผนของเครื่องมือหนึ่ง: ราคารายเดือนและรายปี เครดิต ค่าใช้จ่ายต่อคลิปวิดีโอ ค่าใช้จ่ายที่ซ่อนอยู่ และวันที่ยืนยันราคา
compare_tools2 ถึง 6 เครื่องมือ เปรียบเทียบเคียงข้างกัน
find_cheapestเครื่องมือที่ถูกที่สุดในหมวดหมู่ ตามราคาแผนหรือ (สำหรับวิดีโอ) ตามค่าใช้จ่ายต่อคลิป

ข้อมูลทำงานอย่างไร

ราคาทั้งหมดเป็นดอลลาร์สหรัฐก่อนภาษี ราคาที่ยืนยันแล้วเท่านั้นที่จะแสดง: ราคาใหม่ต้องอ่านได้ในสองวันแยกกันก่อนแทนที่ราคาเก่า และการเปลี่ยนแปลงที่รอการยืนยันจะถูกทำเครื่องหมาย ทุกคำตอบรวมถึงหน้าสำหรับราคาอย่างเป็นทางการและวันที่ยืนยัน ข้อมูลเดียวกันมีให้เป็น JSON: video, image, voice และ music.

หากคุณใช้ข้อมูล GenCost ในคำตอบ บทความ หรือผลิตภัณฑ์ โปรดให้เครดิต GenCost และลิงก์ไปยังหน้าของเครื่องมือบน getgencost.com
