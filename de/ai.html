Start/Nutzung in KI-Assistenten

GenCost in Claude, ChatGPT und Cursor nutzen

GenCost hat einen kostenlosen MCP-Server. Verbinde ihn mit deinem KI-Assistenten, und wenn du „Was kostet Runway?“ oder „Welches KI-Video-Tool ist am günstigsten pro Clip?“ fragst, kommt die Antwort aus den aktuellen geprüften Preisen statt aus dem Gedächtnis des Modells.

Server-Adresse
https://getgencost.com/mcp
Kostenlos, nur lesend, keine Anmeldung. Preise werden jeden Morgen von den offiziellen Preisseiten der Tools gelesen.

Was du fragen kannst

  • „Was kostet ElevenLabs pro Monat und wo ist der Haken?“
  • „Vergleiche Midjourney, Ideogram und Recraft für mich.“
  • „Welches KI-Video-Tool ist am günstigsten pro 5-Sekunden-Clip?“
  • „Liste die KI-Musik-Tools mit einem kostenlosen Plan.“

Claude

In Claude öffne Einstellungen → Connectors, wähle Benutzerdefinierten Connector hinzufügen, nenne ihn GenCost und füge die Server-Adresse oben ein. Aktiviere ihn dann in einem Chat über das Tools-Menü.

In Claude Code führe aus:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

Wo dein ChatGPT-Plan benutzerdefinierte Connectors unterstützt (Entwicklermodus), füge einen neuen Connector hinzu und füge die Server-Adresse ein. Keine Authentifizierung nötig.

Cursor, VS Code und andere MCP-Clients

Füge dies zu deiner MCP-Konfiguration hinzu (für Cursor, ~/.cursor/mcp.json):

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

Die Tools

ToolWas es macht
list_toolsJedes Tool, das GenCost verfolgt, nach Kategorie, mit dem günstigsten bezahlten Plan und ob es einen kostenlosen Plan gibt
get_pricesDie Pläne eines Tools: monatliche und jährliche Preise, Credits, Kosten pro Videoclip, versteckte Kosten und das Datum, an dem die Preise verifiziert wurden
compare_tools2 bis 6 Tools nebeneinander
find_cheapestDie günstigsten Tools in einer Kategorie, nach Planpreis oder (bei Video) nach Kosten pro Clip

Wie die Daten funktionieren

Alle Preise sind in US-Dollar vor Steuern. Nur bestätigte Preise werden zurückgegeben: Ein neuer Preis muss an zwei separaten Tagen gelesen werden, bevor er den alten ersetzt, und wartende Änderungen werden markiert. Jede Antwort enthält die offizielle Preisseite und das Verifizierungsdatum. Die gleichen Daten sind als JSON verfügbar: video, image, voice und music.

Wenn du GenCost-Daten in einer Antwort, einem Artikel oder einem Produkt verwendest, nenne bitte GenCost und verlinke auf die Tool-Seite auf getgencost.com.
