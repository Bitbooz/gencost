ホーム/AIアシスタントで利用

Claude、ChatGPT、CursorでGenCostを利用する

GenCostには無料のMCPサーバーがあります。AIアシスタントに接続すると、「Runwayの料金は？」「AI動画ツールで1クリップあたりの最安値は？」といった質問に対し、モデルの記憶ではなく当日の確認済み価格に基づいた回答が得られます。

サーバーアドレス
https://getgencost.com/mcp
無料、読み取り専用、ログイン不要。価格は毎朝各ツールの公式料金ページから取得しています。

質問例

  • 「ElevenLabsの月額料金と注意点は？」
  • 「Midjourney、Ideogram、Recraftを比較して」
  • 「5秒クリップで最安のAI動画ツールは？」
  • 「無料プランがあるAI音楽ツールを一覧で」

Claude

Claudeでは、設定 → コネクタを開き、カスタムコネクタを追加を選択して名前をGenCostとし、上記のサーバーアドレスを貼り付けてください。その後、ツールメニューからチャットで有効にします。

Claude Codeでは以下を実行します：

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

ChatGPTプランでカスタムコネクタが利用可能な場合（開発者モード）、新しいコネクタを追加してサーバーアドレスを貼り付けてください。認証は不要です。

Cursor、VS Code、その他のMCPクライアント

MCP設定に以下を追加してください（Cursorの場合 ~/.cursor/mcp.json):

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

ツール

ツール機能
list_toolsGenCostが追跡するすべてのツールをカテゴリ別に表示し、最も安い有料プランと無料プランの有無を示します
get_prices1つのツールのプラン：月額と年払いの価格、クレジット、動画クリップあたりのコスト、隠れた費用、価格の確認日
compare_tools2から6のツールを並べて比較
find_cheapestカテゴリ内で最も安いツールを、プラン価格または（動画の場合）クリップあたりのコストで表示

データの仕組み

すべての価格は税抜きの米ドルです。確認済みの価格のみを掲載します。新しい価格は2日以上別々に確認されてから古い価格と置き換わり、確認待ちの変更は明記されます。すべての回答に公式の料金ページと確認日が含まれます。同じデータはJSONでもご利用いただけます：動画、画像、音声、音楽。

GenCostのデータを回答、記事、製品にご利用の際は、GenCostのクレジットを表示し、getgencost.comのツールページへリンクしてください。
