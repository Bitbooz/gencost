Use GenCost in Claude, ChatGPT and Cursor

GenCost has a free MCP server. Connect it to your AI assistant, and when you ask "What does Runway cost?" or "Which AI video tool is cheapest per clip?", the answer comes from today's verified prices instead of the model's memory.

Server address
https://getgencost.com/mcp
Free, read-only, no sign-in. Prices are read from each tool's official pricing page every morning.

What you can ask

  • "What does ElevenLabs cost per month, and what's the catch?"
  • "Compare Midjourney, Ideogram and Recraft for me."
  • "Which AI video tool is cheapest per 5-second clip?"
  • "List the AI music tools with a free plan."

Claude

In Claude, open Settings → Connectors, choose Add custom connector, name it GenCost and paste the server address above. Then turn it on in a chat from the tools menu.

In Claude Code, run:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

Where your ChatGPT plan supports custom connectors (developer mode), add a new connector and paste the server address. No authentication is needed.

Cursor, VS Code and other MCP clients

Add this to your MCP configuration (for Cursor, ~/.cursor/mcp.json):

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

The tools

ToolWhat it does
list_toolsEvery tool GenCost tracks, by category, with its cheapest paid plan and whether it has a free plan
get_pricesOne tool's plans: monthly and yearly prices, credits, cost per video clip, hidden costs and the date the prices were verified
compare_tools2 to 6 tools side by side
find_cheapestThe cheapest tools in a category, by plan price or (for video) by cost per clip

How the data works

All prices are in US dollars before tax. Only confirmed prices are returned: a new price must be read on two separate days before it replaces the old one, and changes waiting for confirmation are marked. Every answer includes the official pricing page and the verification date. The same data is available as JSON: video, image, voice and music.

If you use GenCost data in an answer, an article or a product, please credit GenCost and link to the tool's page on getgencost.com.
