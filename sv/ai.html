Använd GenCost i Claude, ChatGPT och Cursor

GenCost har en gratis MCP-server. Anslut den till din AI-assistent, så kommer svaret från dagens verifierade priser istället för modellens minne när du frågar "Vad kostar Runway?" eller "Vilket AI-video-verktyg är billigast per klipp?".

Serveradress
https://getgencost.com/mcp
Gratis, skrivskyddad, ingen inloggning. Priserna läses från varje verktygs officiella prissida varje morgon.

Vad du kan fråga

  • "Vad kostar ElevenLabs per månad, och vad är haken?"
  • "Jämför Midjourney, Ideogram och Recraft åt mig."
  • "Vilket AI-video-verktyg är billigast per 5-sekunders klipp?"
  • "Lista AI-musikverktygen med en gratis plan."

Claude

I Claude, öppna Inställningar → Connectors, välj Lägg till anpassad connector, namnge den GenCost och klistra in serveradressen ovan. Slå sedan på den i en chatt från verktygsmenyn.

I Claude Code, kör:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

Där din ChatGPT-plan stöder anpassade connectors (utvecklarläge), lägg till en ny connector och klistra in serveradressen. Ingen autentisering behövs.

Cursor

Lägg till detta i ~/.cursor/mcp.json:

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

VS Code (GitHub Copilot)

Lägg till detta i .vscode/mcp.json i ditt projekt, eller till din användarkonfiguration (kommandopalett: MCP: Öppna användarkonfiguration). VS Code använder servers, inte mcpServers:

{ "servers": { "gencost": { "type": "http", "url": "https://getgencost.com/mcp" } } }

Codex (CLI, IDE-tillägg och ChatGPT-skrivbord)

Kör:

codex mcp add gencost --url https://getgencost.com/mcp

eller lägg till detta i ~/.codex/config.toml:

[mcp_servers.gencost]
url = "https://getgencost.com/mcp"

Windsurf

I Cascade-panelen, öppna MCPs och välj Visa rå konfig för att öppna mcp_config.json, lägg till detta, tryck sedan uppdatera:

{ "mcpServers": { "gencost": { "serverUrl": "https://getgencost.com/mcp" } } }

Gemini CLI

Lägg till detta i ~/.gemini/settings.json. Använd httpUrl (inte url, som är för äldre SSE-servrar):

{ "mcpServers": { "gencost": { "httpUrl": "https://getgencost.com/mcp" } } }

Andra MCP-klienter

Alla klienter som stödjer fjärr-MCP-servrar över Streamable HTTP fungerar: använd adressen https://getgencost.com/mcp. Ingen API-nyckel eller inloggning behövs.

Verktygen

VerktygVad det gör
list_toolsVarje verktyg som GenCost spårar, per kategori, med dess billigaste betalda plan och om det har en gratis plan
get_pricesEtt verktygs planer: månads- och årspriser, krediter, kostnad per videoklipp, dolda kostnader och datumet då priserna verifierades
compare_tools2 till 6 verktyg sida vid sida
find_cheapestDe billigaste verktygen i en kategori, efter planpris eller (för video) efter kostnad per klipp

Hur datan fungerar

Alla priser är i amerikanska dollar före skatt. Endast bekräftade priser returneras: ett nytt pris måste läsas på två separata dagar innan det ersätter det gamla, och ändringar som väntar på bekräftelse markeras. Varje svar inkluderar den officiella prissidan och verifieringsdatumet. Samma data finns tillgänglig som JSON: video, image, voice och music.

Om du använder GenCost-data i ett svar, en artikel eller en produkt, vänligen kreditera GenCost och länka till verktygets sida på getgencost.com.
