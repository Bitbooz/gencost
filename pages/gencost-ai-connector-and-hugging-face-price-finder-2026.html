GenCost Now Works in Every AI Assistant, Plus a Free Price Finder on Hugging Face

Quick answer
You can now ask your AI assistant for today's AI tool prices through GenCost's free connector at https://getgencost.com/mcp. Copy-ready setup for Claude, ChatGPT, Cursor, VS Code, Codex, Windsurf and Gemini CLI is on the AI connector page.
No AI assistant? Try the free AI Price Finder on Hugging Face: pick a video model and a number of clips, and see the cheapest platform first.
Both use the same prices as this site, read from each official pricing page every morning.
Last checked: 2026-11-18

More and more people ask an AI assistant before they buy. So GenCost now answers where those questions are asked: inside the assistants people already use, and on Hugging Face, where the AI community shares tools.

Ask your AI assistant for today's prices

GenCost runs a free, read-only MCP server (an "AI connector"). Once it's added, you can ask things like:

  • "What's the cheapest way to make 20 Kling 4.0 clips this month?"
  • "Compare Runway and Pika plans."
  • "Which AI voice tool has the cheapest paid plan today?"

The assistant gets the answer from GenCost's live data instead of guessing from old training data. There is no sign-in and no API key.

Now with setup for seven apps

The AI connector page has a short, copy-ready setup for each app, checked against each app's own documentation:

  • Claude and Claude Code
  • ChatGPT
  • Cursor
  • VS Code (GitHub Copilot), new
  • Codex (CLI, IDE extension and ChatGPT desktop), new
  • Windsurf, new
  • Gemini CLI, new

Any other app that supports remote MCP servers works too: just use the address https://getgencost.com/mcp.

New: AI Price Finder on Hugging Face

AI Price Finder is a free little app on Hugging Face with three tabs:

  • Cost of video clips: choose a model such as Kling 4.0, Seedance 2.5 or Ray3.2, how many clips and how many seconds, and see the cheapest plan on each platform that covers them.
  • Cheapest plans for video, image, voice or music.
  • One tool: every plan of one tool, with a link to its official pricing page.

It reads the open AI tool prices dataset live, so it's always up to date. The dataset is free to use (CC BY 4.0) if you want to build something yourself.

The same prices everywhere

The website, the AI connector, the Hugging Face app and the dataset all use the same numbers. Every morning GenCost reads each tool's official pricing page, and a price change is only published after it has been seen on two different days.
