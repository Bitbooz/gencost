Використовуйте GenCost у Claude, ChatGPT та Cursor

GenCost має безкоштовний MCP-сервер. Підключіть його до свого AI-асистента, і коли ви запитаєте «Скільки коштує Runway?» або «Який AI-інструмент для відео найдешевший за кліп?», відповідь буде з сьогоднішніх перевірених цін, а не з пам’яті моделі.

Адреса сервера
https://getgencost.com/mcp
Безкоштовно, лише для читання, без входу. Ціни зчитуються з офіційної сторінки тарифів кожного інструмента щодня вранці.

Що можна запитати

  • «Скільки коштує ElevenLabs на місяць і в чому підступ?»
  • «Порівняй Midjourney, Ideogram і Recraft.»
  • «Який AI-інструмент для відео найдешевший за 5-секундний кліп?»
  • «Перелічи AI-інструменти для музики з безкоштовним тарифом.»

Claude

У Claude відкрийте Налаштування → Конектори, оберіть Додати власний конектор, назвіть його GenCost і вставте адресу сервера вище. Потім увімкніть його в чаті з меню інструментів.

У Claude Code виконайте:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

Там, де ваш тариф ChatGPT підтримує власні конектори (режим розробника), додайте новий конектор і вставте адресу сервера. Автентифікація не потрібна.

Cursor, VS Code та інші MCP-клієнти

Додайте це до конфігурації MCP (для Cursor, ~/.cursor/mcp.json):

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

Як працюють дані

Усі ціни вказано в доларах США без податків. Повертаються лише підтверджені ціни: нова ціна має бути зчитана в два окремі дні, перш ніж замінити стару, а зміни, що очікують підтвердження, позначені. Кожна відповідь містить офіційну сторінку з цінами та дату перевірки. Ті самі дані доступні як JSON: відео, зображення, голос та музика.

Якщо ви використовуєте дані GenCost у відповіді, статті чи продукті, будь ласка, вкажіть GenCost і додайте посилання на сторінку інструменту на getgencost.com.
