Boîte de prix IA gratuite pour votre site web ou blog

Réponse rapide
Vous pouvez ajouter une boîte de prix gratuite pour n’importe lequel des 50 outils IA suivis par GenCost sur votre propre site web ou blog. Copiez deux lignes de code en bas de n’importe quelle page d’outil sur GenCost ; la boîte affiche les forfaits et prix du jour et se met à jour seule chaque matin. Aucune inscription, aucune clé, aucun suivi.
Dernière vérification : 2026-11-21

Vous écrivez sur Runway, Kling, ElevenLabs ou Suno ? Les prix de l’IA changent souvent, donc un prix que vous avez tapé dans un article le mois dernier peut déjà être faux. La boîte de prix GenCost le garde à jour pour vous.

Comment l’ajouter (1 minute)

  1. Ouvrez la page GenCost de l’outil dont vous parlez, par exemple Runway, Kling ou ElevenLabs.
  2. Faites défiler jusqu’en bas, jusqu’à « Ajouter cette boîte de prix à votre site », et copiez le code.
  3. Collez-le dans votre page ou article à l’endroit où la boîte doit apparaître (dans WordPress : un bloc « HTML personnalisé »).

Le code ressemble à ceci :

<div class="gencost-prices" data-tool="Runway" data-cat="video">
  <a href="https://getgencost.com/pages/runway.html">Runway pricing</a> by GenCost
</div>
<script src="https://getgencost.com/embed.js" async></script>

Pour un site sombre, ajoutez data-theme="dark" à la première ligne.

Ce que la boîte affiche

  • Chaque forfait de l’outil, avec le prix mensuel et le prix en paiement annuel.
  • Crédits ou minutes par forfait.
  • La date de vérification des prix et un lien vers la comparaison complète sur GenCost.

Pourquoi c’est gratuit

GenCost lit chaque matin la page tarifaire officielle de chaque outil et souhaite que ces chiffres soient utilisés. La boîte renvoie vers GenCost, c’est tout ce que nous demandons. Il n’y a ni pubs, ni liens d’affiliation, ni cookies dans la boîte.

Questions fréquentes

La boîte de prix ralentit-elle mon site ?

Non. Le script se charge après votre page (async) et les prix sont un petit fichier mis en cache par les navigateurs.

Quels outils puis-je afficher ?

N’importe lequel des 50 outils IA vidéo, image, voix et musique sur GenCost, par exemple Runway, Kling, Pika, Higgsfield, Midjourney, ElevenLabs et Suno. Le code se trouve sur la page de chaque outil.

Les assistants IA peuvent-ils utiliser les mêmes prix ?

Oui. GenCost propose aussi un connecteur IA gratuit (MCP) pour Claude, ChatGPT, Cursor et d’autres, ainsi qu’un jeu de données ouvert sur Hugging Face.

GenCost n’a aucun lien d’affiliation ni de placement payant. Les prix sont lus chaque matin sur la page tarifaire officielle de chaque outil.
