Usa GenCost in Claude, ChatGPT e Cursor

GenCost ha un server MCP gratuito. Collegalo al tuo assistente AI e quando chiedi "Quanto costa Runway?" o "Quale tool AI video è il più economico per clip?", la risposta arriva dai prezzi verificati di oggi invece che dalla memoria del modello.

Indirizzo del server
https://getgencost.com/mcp
Gratuito, sola lettura, senza login. I prezzi vengono letti ogni mattina dalla pagina prezzi ufficiale di ogni tool.

Cosa puoi chiedere

  • "Quanto costa ElevenLabs al mese e qual è il trucco?"
  • "Confronta Midjourney, Ideogram e Recraft per me."
  • "Quale tool AI video è il più economico per un clip di 5 secondi?"
  • "Elenca i tool AI per musica con un piano gratuito."

Claude

In Claude, apri Impostazioni → Connettori, scegli Aggiungi connettore personalizzato, chiamalo GenCost e incolla l'indirizzo del server sopra. Poi attivalo in una chat dal menu strumenti.

In Claude Code, esegui:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

Dove il tuo piano ChatGPT supporta connettori personalizzati (modalità sviluppatore), aggiungi un nuovo connettore e incolla l'indirizzo del server. Non serve autenticazione.

Cursor, VS Code e altri client MCP

Aggiungi questo alla tua configurazione MCP (per Cursor, ~/.cursor/mcp.json):

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

Gli strumenti

StrumentoCosa fa
list_toolsOgni strumento tracciato da GenCost, per categoria, con il suo piano a pagamento più economico e se ha un piano gratuito
get_pricesI piani di uno strumento: prezzi mensili e annuali, crediti, costo per clip video, costi nascosti e data di verifica dei prezzi
compare_tools2 a 6 strumenti a confronto
find_cheapestGli strumenti più economici in una categoria, per prezzo del piano o (per i video) per costo per clip

Come funzionano i dati

Tutti i prezzi sono in dollari USA prima delle tasse. Vengono restituiti solo prezzi confermati: un nuovo prezzo deve essere letto in due giorni separati prima di sostituire quello vecchio, e le modifiche in attesa di conferma sono indicate. Ogni risposta include la pagina ufficiale dei prezzi e la data di verifica. Gli stessi dati sono disponibili come JSON: video, immagine, voce e musica.

Se usi i dati di GenCost in una risposta, un articolo o un prodotto, cita GenCost e collega alla pagina dello strumento su getgencost.com.
