GenCost Project Overview

Project: Real-time AI-powered price comparison tool for AI video and avatar platforms

Goal: Automated checks + LLM extraction so prices, credits, free tiers and offers stay up to date. Clean webpage that shows real cost per minute/clip so users can compare easily.

Version 1 features

  • Automated checks on key platforms
  • AI extraction to structured data
  • Normalized costs (per credit, per minute, per clip)
  • Simple comparison webpage with last-updated timestamp
  • Change highlighting and basic deal detection

Platforms for v1: HeyGen, Higgsfield, Runway, Kling AI, Synthesia, Pika
