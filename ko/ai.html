Claude, ChatGPT, Cursor에서 GenCost 사용하기

GenCost는 무료 MCP 서버를 제공합니다. AI 어시스턴트에 연결하면 "Runway 비용이 얼마인가요?" 또는 "AI 비디오 도구 중 클립당 가장 저렴한 것은?" 같은 질문에 모델의 기억이 아닌 오늘 확인된 가격으로 답변합니다.

서버 주소
https://getgencost.com/mcp
무료, 읽기 전용, 로그인 불필요. 가격은 매일 아침 각 도구의 공식 가격 페이지에서 읽어옵니다.

할 수 있는 질문

  • "ElevenLabs의 월 비용과 주의할 점은 무엇인가요?"
  • "Midjourney, Ideogram, Recraft를 비교해 주세요."
  • "5초 클립 기준으로 가장 저렴한 AI 비디오 도구는?"
  • "무료 요금제가 있는 AI 음악 도구를 알려 주세요."

Claude

Claude에서 설정 → 커넥터를 열고 커스텀 커넥터 추가를 선택한 후, 이름을 GenCost로 지정하고 위 서버 주소를 붙여넣으세요. 그런 다음 도구 메뉴에서 채팅에 켜세요.

Claude Code에서는 다음을 실행하세요:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

ChatGPT 요금제가 커스텀 커넥터를 지원하는 경우(개발자 모드), 새 커넥터를 추가하고 서버 주소를 붙여넣으세요. 인증은 필요 없습니다.

Cursor, VS Code 및 기타 MCP 클라이언트

MCP 구성에 다음을 추가하세요(Cursor의 경우 ~/.cursor/mcp.json):

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

도구

도구기능
list_toolsGenCost가 추적하는 모든 도구를 카테고리별로, 가장 저렴한 유료 플랜과 무료 플랜 유무와 함께 표시합니다
get_prices한 도구의 플랜: 월간 및 연간 가격, 크레딧, 비디오 클립당 비용, 숨겨진 비용과 가격 확인일
compare_tools2~6개 도구를 나란히 비교
find_cheapest카테고리별 가장 저렴한 도구를 플랜 가격 또는 (비디오는) 클립당 비용 기준으로 표시

데이터 작동 방식

모든 가격은 세금 전 미국 달러입니다. 확인된 가격만 표시합니다. 새 가격은 이틀 이상 별도로 확인해야 기존 가격을 대체하며, 확인 대기 중인 변경 사항은 별도로 표시합니다. 모든 답변에 공식 가격 페이지와 확인일을 포함합니다. 동일한 데이터는 JSON으로도 제공됩니다: video, image, voice, music.

GenCost 데이터를 답변, 기사 또는 제품에 사용하실 경우 GenCost를 인용하고 getgencost.com의 해당 도구 페이지로 링크해 주세요.
