점점 더 많은 사람들이 구매 전에 AI 어시스턴트에게 물어보고 있습니다. 그래서 GenCost는 이제 사람들이 이미 사용하는 어시스턴트 내부와 AI 커뮤니티가 도구를 공유하는 Hugging Face에서 이러한 질문에 답변합니다.

오늘의 가격을 AI 어시스턴트에게 물어보세요

GenCost는 무료 읽기 전용 MCP server( "AI connector" )를 운영합니다. 추가하면 다음과 같이 물어볼 수 있습니다:

  • "이번 달에 20개의 Kling 4.0 클립을 만드는 가장 저렴한 방법은 무엇인가요?"
  • "Runway와 Pika 요금제를 비교해 주세요."
  • "오늘 가장 저렴한 유료 요금제를 제공하는 AI 음성 도구는 무엇인가요?"

어시스턴트는 오래된 학습 데이터로 추측하는 대신 GenCost의 실시간 데이터에서 답변을 가져옵니다. 로그인이나 API 키가 필요 없습니다.

이제 7개 앱에 대한 설정 지원

AI connector 페이지에는 각 앱의 공식 문서를 확인한 후 복사해 바로 사용할 수 있는 간단한 설정이 있습니다:

  • Claude 및 Claude Code
  • ChatGPT
  • Cursor
  • VS Code (GitHub Copilot), 신규
  • Codex (CLI, IDE 확장 및 ChatGPT 데스크톱), 신규
  • Windsurf, 신규
  • Gemini CLI, 신규

원격 MCP 서버를 지원하는 다른 앱도 사용할 수 있습니다. 주소만 입력하세요 https://getgencost.com/mcp.

신규: Hugging Face의 AI Price Finder

AI Price Finder는 Hugging Face에서 제공하는 무료 소형 앱으로 세 개의 탭이 있습니다:

  • Cost of video clips: Kling 4.0, Seedance 2.5 또는 Ray3.2 같은 모델을 선택하고 클립 수와 초 수를 입력하면 해당 클립을 커버하는 각 플랫폼의 가장 저렴한 요금제를 확인할 수 있습니다.
  • 영상, 이미지, 음성 또는 음악용 Cheapest plans.
  • 하나의 도구에 대한 One tool: 모든 요금제와 공식 가격 페이지 링크.

공개된 AI tool prices dataset을 실시간으로 읽어 항상 최신 상태를 유지합니다. 직접 무언가를 만들고 싶다면 이 데이터셋은 무료로 사용할 수 있습니다(CC BY 4.0).

모든 곳에서 동일한 가격

웹사이트, AI connector, Hugging Face 앱, 데이터셋 모두 동일한 숫자를 사용합니다. GenCost는 매일 아침 각 도구의 공식 가격 페이지를 읽으며, 가격 변경은 서로 다른 두 날에 확인된 후에만 게시됩니다.
