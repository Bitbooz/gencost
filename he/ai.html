שימוש ב-GenCost ב-Claude, ChatGPT ו-Cursor

ל-GenCost יש שרת MCP חינמי. מחברים אותו לעוזר ה-AI, וכששואלים "כמה עולה Runway?" או "איזה כלי וידאו AI הכי זול לקליפ?", התשובה מגיעה מהמחירים המאומתים של היום במקום מהזיכרון של המודל.

כתובת השרת
https://getgencost.com/mcp
חינמי, לקריאה בלבד, בלי הרשמה. המחירים נקראים מדף התמחור הרשמי של כל כלי כל בוקר.

מה אפשר לשאול

  • "כמה עולה ElevenLabs לחודש, ומה הקאץ'?"
  • "השווה לי בין Midjourney, Ideogram ו-Recraft."
  • "איזה כלי וידאו AI הכי זול לקליפ של 5 שניות?"
  • "רשום לי את כלי המוזיקה עם תוכנית חינמית."

Claude

ב-Claude, פותחים Settings ← Connectors, בוחרים Add custom connector, נותנים לו שם GenCost ומדביקים את כתובת השרת למעלה. אחר כך מפעילים אותו בצ'אט מתפריט הכלים.

ב-Claude Code, מריצים:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

במקום שבו תוכנית ChatGPT תומכת במחברים מותאמים אישית (מצב מפתחים), מוסיפים מחבר חדש ומדביקים את כתובת השרת. אין צורך באימות.

Cursor, VS Code ולקוחות MCP אחרים

מוסיפים את זה להגדרות ה-MCP (עבור Cursor, ~/.cursor/mcp.json):

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

איך הנתונים עובדים

כל המחירים בדולרים אמריקאים לפני מס. רק מחירים מאושרים מוחזרים: מחיר חדש חייב להיקרא בשני ימים נפרדים לפני שהוא מחליף את הישן, ושינויים הממתינים לאישור מסומנים. כל תשובה כוללת את דף התמחור הרשמי ותאריך האימות. אותם נתונים זמינים כ-JSON: וידאו, תמונה, קול ומוזיקה.

אם אתה משתמש בנתוני GenCost בתשובה, מאמר או מוצר, אנא קרדיט ל-GenCost וקשר לדף הכלי ב-getgencost.com.
