Brug GenCost i Claude, ChatGPT og Cursor

GenCost har en gratis MCP-server. Tilslut den til din AI-assistent, og når du spørger "Hvad koster Runway?" eller "Hvilket AI-videoværktøj er billigst pr. klip?", kommer svaret fra dagens verificerede priser i stedet for modellens hukommelse.

Serveradresse
https://getgencost.com/mcp
Gratis, read-only, ingen login. Priser læses fra hvert værktøjs officielle prisside hver morgen.

Hvad du kan spørge om

  • "Hvad koster ElevenLabs om måneden, og hvad er hagen?"
  • "Sammenlign Midjourney, Ideogram og Recraft for mig."
  • "Hvilket AI-videoværktøj er billigst pr. 5-sekunders klip?"
  • "Vis AI-musikværktøjer med en gratis plan."

Claude

I Claude åbner du Indstillinger → Connectors, vælger Add custom connector, navngiver den GenCost og indsætter serveradressen ovenfor. Slå den derefter til i en chat fra værktøjsmenuen.

I Claude Code kører du:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

Hvor din ChatGPT-plan understøtter custom connectors (developer mode), tilføjer du en ny connector og indsætter serveradressen. Ingen godkendelse kræves.

Cursor

Tilføj dette til ~/.cursor/mcp.json:

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

VS Code (GitHub Copilot)

Tilføj dette til .vscode/mcp.json i dit projekt, eller til din brugerindstilling (kommandopalet: MCP: Open User Configuration). VS Code bruger servers, ikke mcpServers:

{ "servers": { "gencost": { "type": "http", "url": "https://getgencost.com/mcp" } } }

Codex (CLI, IDE-udvidelse og ChatGPT desktop)

Kør:

codex mcp add gencost --url https://getgencost.com/mcp

eller tilføj dette til ~/.codex/config.toml:

[mcp_servers.gencost]
url = "https://getgencost.com/mcp"

Windsurf

I Cascade-panelet, åbn MCPs og vælg Vis rå konfiguration for at åbne mcp_config.json, tilføj dette, og tryk derefter opdater:

{ "mcpServers": { "gencost": { "serverUrl": "https://getgencost.com/mcp" } } }

Gemini CLI

Tilføj dette til ~/.gemini/settings.json. Brug httpUrl (ikke url, som er til ældre SSE-servere):

{ "mcpServers": { "gencost": { "httpUrl": "https://getgencost.com/mcp" } } }

Andre MCP-klienter

Enhver klient der understøtter fjern-MCP-servere over Streamable HTTP virker: brug adressen https://getgencost.com/mcp. Ingen API-nøgle eller login er nødvendig.

Værktøjerne

VærktøjHvad det gør
list_toolsHvert værktøj GenCost sporer, efter kategori, med dets billigste betalte plan og om det har en gratis plan
get_pricesEt værktøjs planer: månedlige og årlige priser, kreditter, pris per videoklip, skjulte omkostninger og datoen priserne blev verificeret
compare_tools2 til 6 værktøjer side om side
find_cheapestDe billigste værktøjer i en kategori, efter planpris eller (for video) efter pris per klip

Sådan fungerer dataene

Alle priser er i US dollars før skat. Kun bekræftede priser returneres: en ny pris skal læses på to separate dage, før den erstatter den gamle, og ændringer der venter på bekræftelse er markeret. Hvert svar inkluderer den officielle prisside og verificeringsdatoen. De samme data er tilgængelige som JSON: video, billede, stemme og musik.

Hvis du bruger GenCost-data i et svar, en artikel eller et produkt, så krediter GenCost og link til værktøjets side på getgencost.com.
