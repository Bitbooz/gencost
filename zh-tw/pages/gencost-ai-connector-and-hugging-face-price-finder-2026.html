GenCost 現已支援所有 AI 助理，並在 Hugging Face 提供免費價格查詢工具

快速回答
你現在可以透過 GenCost 的免費連接器，向 AI 助理詢問今日 AI 工具價格： https://getgencost.com/mcp。適用於 Claude、ChatGPT、Cursor、VS Code、Codex、Windsurf 與 Gemini CLI 的即用設定已公布於 AI 連接器頁面.
沒有 AI 助理？可試用免費的 Hugging Face AI 價格查詢工具：選擇影片模型與片段數量，即可看到最便宜的平台。
兩者價格皆與本站相同，每早從各官方定價頁讀取。
最後檢查：2026-11-18

越來越多人會先問 AI 助理再購買。因此 GenCost 現在會在人們使用的助理內，以及 AI 社群分享工具的 Hugging Face 上回答這些問題。

向你的 AI 助理詢問今日價格

GenCost 提供免費唯讀的 MCP server（「AI 連接器」）。加入後，你可以詢問例如：

  • 「這個月製作 20 個 Kling 4.0 片段最便宜的方式是什麼？」
  • 「比較 Runway 與 Pika 的方案。」
  • 「哪個 AI 語音工具的付費方案今天最便宜？」

助理會從 GenCost 的即時資料取得答案，而非依賴舊訓練資料猜測。無需登入，也不需要 API 金鑰。

現已支援七款應用程式

AI 連接器頁面提供每款應用程式的簡短設定檔，可直接複製，並已依各應用程式官方文件確認：

  • Claude 與 Claude Code
  • ChatGPT
  • Cursor
  • VS Code（GitHub Copilot），新增
  • Codex（CLI、IDE 擴充功能與 ChatGPT 桌面版），新增
  • Windsurf，新增
  • Gemini CLI，新增

其他支援遠端 MCP server 的應用程式也能使用，只要輸入位址 https://getgencost.com/mcp.

新功能：Hugging Face 上的 AI Price Finder

AI Price Finder 是 Hugging Face 上的免費小工具，包含三個分頁：

  • 影片片段成本：選擇 Kling 4.0、Seedance 2.5 或 Ray3.2 等模型，輸入片段數與秒數，即可查看各平台涵蓋需求的最便宜方案。
  • 最便宜方案：影片、圖像、語音或音樂。
  • 單一工具：查看單一工具的所有方案，並附官方定價頁連結。

它即時讀取開放的 AI tool prices dataset，因此資料永遠保持最新。該資料集可免費使用（CC BY 4.0），適合自行開發應用。

價格同步更新

網站、AI 連接器、Hugging Face 應用程式與資料集皆使用相同數字。GenCost 每天早上讀取各工具的官方定價頁，價格變動需在兩個不同日期確認後才會發布。
