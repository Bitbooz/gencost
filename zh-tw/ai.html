在 Claude、ChatGPT 與 Cursor 中使用 GenCost

GenCost 提供免費 MCP 伺服器。連線到你的 AI 助理後，當你詢問「Runway 要多少錢？」或「哪個 AI 影片工具每段最便宜？」時，答案會來自今天驗證過的價格，而非模型的記憶。

伺服器位址
https://getgencost.com/mcp
免費、唯讀、無需登入。價格每天早上從各工具的官方定價頁面讀取。

你可以問什麼

  • 「ElevenLabs 每月要多少錢，有什麼要注意的嗎？」
  • 「幫我比較 Midjourney、Ideogram 和 Recraft。」
  • 「哪個 AI 影片工具的 5 秒片段最便宜？」
  • 「列出有免費方案的 AI 音樂工具。」

Claude

在 Claude 中，開啟 設定 → 連接器，選擇 新增自訂連接器，命名為 GenCost，然後貼上上方伺服器位址。接著在聊天工具選單中開啟它。

在 Claude Code 中執行：

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

如果你的 ChatGPT 方案支援自訂連接器（開發者模式），新增一個連接器並貼上伺服器位址。無需驗證。

Cursor、VS Code 與其他 MCP 用戶端

將此加入你的 MCP 設定（適用於 Cursor， ~/.cursor/mcp.json):

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

工具

工具功能說明
list_toolsGenCost 追蹤的所有工具，按類別分類，附上最便宜的付費方案以及是否有免費方案
get_prices單一工具的方案：每月與年繳價格、點數、每段影片成本、隱藏費用以及價格驗證日期
compare_tools2 到 6 項工具並排比較
find_cheapest各類別中最便宜的工具，以方案價格或（影片類）每段剪輯成本排序

資料運作方式

所有價格為稅前美元。只有確認過的價格才會顯示：新價格必須在兩個不同日子讀取後才會取代舊價格，等待確認的變更會標記。每個答案都包含官方定價頁面與驗證日期。相同資料也可作為 JSON 取得：video、image、voice 與 music。

若您在答案、文章或產品中使用 GenCost 資料，請註明出處並連結至 getgencost.com 上的工具頁面。
