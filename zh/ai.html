在 Claude、ChatGPT 和 Cursor 中使用 GenCost

GenCost 提供免费 MCP 服务器。连接到你的 AI 助手后，当你询问「Runway 多少钱？」或「哪个 AI 视频工具每段剪辑最便宜？」时，答案将来自当天已验证的价格，而非模型的记忆。

服务器地址
https://getgencost.com/mcp
免费、只读、无需登录。价格每天早上从每个工具的官方定价页面读取。

你可以询问什么

  • 「ElevenLabs 每月多少钱，有什么注意事项？」
  • 「帮我对比 Midjourney、Ideogram 和 Recraft。」
  • 「哪个 AI 视频工具的 5 秒剪辑最便宜？」
  • 「列出有免费方案的 AI 音乐工具。」

Claude

在 Claude 中，打开 设置 → 连接器，选择 添加自定义连接器，命名为 GenCost，然后粘贴上方服务器地址。接着在聊天中从工具菜单开启它。

在 Claude Code 中，运行：

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

如果你的 ChatGPT 方案支持自定义连接器（开发者模式），添加新连接器并粘贴服务器地址。无需身份验证。

Cursor、VS Code 和其他 MCP 客户端

将此添加到你的 MCP 配置中（适用于 Cursor， ~/.cursor/mcp.json):

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

工具

工具功能
list_toolsGenCost 追踪的每款工具，按类别分类，显示其最便宜的付费计划以及是否有免费计划
get_prices一款工具的计划：每月和每年价格、积分、每个视频片段的成本、隐藏成本以及价格验证日期
compare_tools2 至 6 款工具并排比较
find_cheapest按计划价格（或视频按每个片段成本）分类的最便宜工具

数据如何运作

所有价格均为税前美元价格。仅返回已确认的价格：新价格必须在两个不同日期读取后才能替换旧价格，等待确认的变更会被标记。每个答案都包含官方定价页面和验证日期。相同数据以 JSON 形式提供：video、image、voice 和 music。

如果您在答案、文章或产品中使用 GenCost 数据，请注明 GenCost 并链接到 getgencost.com 上的工具页面。
