GenCost теперь работает в каждом AI-ассистенте, плюс бесплатный поиск цен на Hugging Face

Короткий ответ
Теперь можно спросить у AI-ассистента актуальные цены на AI-инструменты через бесплатный коннектор GenCost по адресу https://getgencost.com/mcp. Готовые настройки для Claude, ChatGPT, Cursor, VS Code, Codex, Windsurf и Gemini CLI находятся на странице AI-коннектора.
Нет AI-ассистента? Попробуйте бесплатный AI Price Finder на Hugging Face: выберите видео-модель и количество клипов, и сразу увидите самую дешёвую платформу.
Оба используют те же цены, что и этот сайт, считанные с каждой официальной страницы цен каждое утро.
Последняя проверка: 2026-11-18

Всё больше людей спрашивают у AI-ассистента перед покупкой. Поэтому GenCost теперь отвечает там, где задают эти вопросы: внутри уже привычных ассистентов и на Hugging Face, где AI-сообщество делится инструментами.

Спросите у своего AI-ассистента актуальные цены

GenCost запускает бесплатный read-only MCP server («AI connector»). После добавления вы можете спрашивать, например:

  • «Как дешевле сделать 20 клипа Kling 4.0 в этом месяце?»
  • «Сравни тарифы Runway и Pika.»
  • «У какого AI-голосового инструмента сейчас самый дешёвый платный тариф?»

Ассистент получает ответ из актуальных данных GenCost, а не угадывает по старым обучающим данным. Без входа и без API-ключа.

Теперь с настройкой для семи приложений

На странице AI connector есть короткая готовая настройка для каждого приложения, проверенная по документации самих приложений:

  • Claude и Claude Code
  • ChatGPT
  • Cursor
  • VS Code (GitHub Copilot), новое
  • Codex (CLI, расширение для IDE и десктоп ChatGPT), новое
  • Windsurf, новое
  • Gemini CLI, новое

Подойдёт и любое другое приложение, поддерживающее удалённые MCP-серверы: просто используйте адрес https://getgencost.com/mcp.

Новое: AI Price Finder на Hugging Face

AI Price Finder — бесплатное небольшое приложение на Hugging Face с тремя вкладками:

  • Cost of video clips: выберите модель, например Kling 4.0, Seedance 2.5 или Ray3.2, укажите количество клипов и секунд — и увидите самый дешёвый тариф на каждой платформе, который их покрывает.
  • Cheapest plans для видео, изображений, голоса или музыки.
  • One tool: все тарифы одного инструмента со ссылкой на его официальную страницу цен.

Приложение читает открытый AI tool prices dataset в реальном времени, поэтому данные всегда актуальны. Датасет бесплатный (CC BY 4.0), если хотите использовать его для своих проектов.

Одинаковые цены везде

Сайт, AI connector, приложение на Hugging Face и датасет используют одни и те же цифры. Каждое утро GenCost считывает официальные страницы цен каждого инструмента, и изменение публикуется только после подтверждения в два разных дня.
