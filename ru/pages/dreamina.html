О Dreamina

Dreamina — приложение ByteDance для генерации изображений и видео (от создателей CapCut) и дом для видео-моделей Seedance.

Для кого

Использование видео-моделей Seedance напрямую, плюс генерация изображений, в одном приложении.

Бесплатный тариф

Есть бесплатный вариант с ограниченным ежедневным использованием.

Как работают кредиты

Каждый план даёт фиксированное количество кредитов в месяц (Basic 1,575). Seedance 2.5 использует 37 кредитов за секунду при 720p. Первый месяц каждого плана со скидкой, поэтому со второго месяца стоимость выше.

FAQ по ценам Dreamina

Сколько стоит Dreamina?

Самый дешёвый платный план Dreamina — Basic за $15 в месяц. Самый большой план, который мы отслеживаем, — Ultra за $520 в месяц. Цены проверены 2026-11-14.

Есть ли у Dreamina бесплатный план?

Есть бесплатный вариант с ограниченным ежедневным использованием.

Сколько стоит один видеоклип на Dreamina?

На плане Basic один 10-секундный клип с Seedance 2.5, 720p стоит около $3.52 (370 кредитов). Мы рассчитываем это по собственным кредитам Dreamina за клип и текущей цене плана; более высокие разрешения и премиум-модели стоят дороже. Если обычно нужно 3 попыток на каждый сохранённый клип, рассчитывайте примерно $10.57 за сохранённый клип.

Есть ли скрытые расходы в Dreamina?

Первый месяц со скидкой (Basic $0.29); после этого Basic — $15 в месяц. На странице цен нет годовых тарифов, только метка «40% скидка».
