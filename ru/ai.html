Используйте GenCost в Claude, ChatGPT и Cursor

У GenCost есть бесплатный MCP-сервер. Подключите его к своему AI-ассистенту, и когда вы спросите «Сколько стоит Runway?» или «Какой AI-инструмент для видео дешевле всего за клип?», ответ будет основан на сегодняшних проверенных ценах, а не на памяти модели.

Адрес сервера
https://getgencost.com/mcp
Бесплатно, только чтение, без входа. Цены считываются каждое утро с официальных страниц тарифов инструментов.

Что можно спрашивать

  • «Сколько стоит ElevenLabs в месяц и в чём подвох?»
  • «Сравни Midjourney, Ideogram и Recraft.»
  • «Какой AI-инструмент для видео дешевле всего за 5-секундный клип?»
  • «Перечисли AI-инструменты для музыки с бесплатным тарифом.»

Claude

В Claude откройте Настройки → Коннекторы, выберите Добавить кастомный коннектор, назовите его GenCost и вставьте адрес сервера выше. Затем включите его в чате через меню инструментов.

В Claude Code выполните:

claude mcp add --transport http gencost https://getgencost.com/mcp

ChatGPT

Если ваш тариф ChatGPT поддерживает кастомные коннекторы (режим разработчика), добавьте новый коннектор и вставьте адрес сервера. Авторизация не требуется.

Cursor, VS Code и другие MCP-клиенты

Добавьте это в конфигурацию MCP (для Cursor, ~/.cursor/mcp.json):

{ "mcpServers": { "gencost": { "url": "https://getgencost.com/mcp" } } }

Инструменты

compare_tools2–6 инструментов рядом
find_cheapestСамые дешёвые инструменты в категории по цене плана или (для видео) по стоимости за клип

Как работают данные

Все цены указаны в долларах США до налогов. Возвращаются только подтверждённые цены: новая цена должна быть прочитана в два разных дня, прежде чем заменит старую, а ожидающие подтверждения изменения отмечены. Каждый ответ включает официальную страницу цен и дату проверки. Те же данные доступны как JSON: видео, изображение, голос и музыка.

Если вы используете данные GenCost в ответе, статье или продукте, укажите авторство GenCost и ссылку на страницу инструмента на getgencost.com.
